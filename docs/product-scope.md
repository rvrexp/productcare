\# ProductCare V1 Scope



ProductCare is a portfolio project for demonstrating a production-oriented

Azure AI application using .NET and React Native.



The first release focuses on four user journeys:



\- Identify a product from a model-label photo.

\- Check the product against CPSC recall information.

\- Answer questions using product documentation with citations.

\- Track basic maintenance and warranty information.



The AI layer will use specialist agents, but the application should only

invoke the agents needed for a request.



\## Out of scope for V1



Voice, video, marketplace features, social features, paid subscriptions,

and technician booking.



The main constraint is a two-week implementation window, so features that

do not strengthen the core demo will be deferred.
